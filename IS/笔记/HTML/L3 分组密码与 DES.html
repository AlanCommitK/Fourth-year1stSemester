Lecture 3 — Block Ciphers and the Data Encryption Standard

分组密码与 DES

怎样造一个密钥短、可反复使用、算法完全公开也没人破得了的密码？这一讲从「理想分组密码造不出来」出发，经香农的扩散与混淆、Feistel 结构，落到 DES 这个实例，再看它为什么败在 56 位密钥上、2DES 为什么救不了它。

主线这一讲在做什么

L2 的结尾留下三样东西：一次一密不可破却没法用；双重置换说明「重复一个弱操作能得到强操作」；香农把密码该做的事命名为混淆与扩散。这一讲把它们接成一条因果链，回答课件开头提的问题：怎样造一个密钥短、可反复使用、算法完全公开也没人破得了的密码？

  1. 最理想的分组密码在结构上无懈可击，但它的密钥是一整张表，长到存不下 → 只能近似它；
  2. 近似要达到什么？所有古典攻击都靠明文的统计规律漏进密文 → 香农的两个目标：扩散切断明文与密文的统计联系，混淆切断密钥与密文的联系；
  3. 用什么搭？交替做代换和置换、重复很多轮——Feistel 结构让这种多轮密码不管轮函数可不可逆都能解密；
  4. 一个具体实例：DES，用雪崩效应检验它是否做到了扩散与混淆；
  5. 强度由什么决定？轮数、轮函数、密钥编排三个设计杠杆，外加密钥长度。DES 正是败在密钥长度上，于是有了 2DES 的失败、3DES 的过渡和 AES。

这里提到的术语都在下文对应小节定义。课件的五个部分本来就是按这条链排的，本笔记沿用原顺序，只做两处补充：课件没给的 DES 内部结构（轮函数 F、S 盒、密钥编排的细节）补在第 6 节；Feistel 解密正确性的完整推导补在 5.4。

1起点：一次一密之后

1.1课后题讲评：密钥重用丢了什么

课件第 2 页先讲评 L2 的课后题。L2 §8.5「密钥重用的代价」那一题：两条消息用同一段密钥流 k 做异或加密，攻击者把两段密文异或，

c1 ⊕ c2 = (p1 ⊕ k) ⊕ (p2 ⊕ k) = p1 ⊕ p2(1)

密钥被完全消掉，剩下两段明文的异或，带着英文的全部统计规律，猜中一条里的一个词就能读出另一条对应位置的内容。这种失败叫两次一密（two-time pad）：一次一密的密钥被用了两次。它在真实部署的系统里出过事。

课件借这道题追问了三件事：

  • 哪个条件被破坏了？ 一次一密的三个条件（L2 §8.2：真随机、与消息等长、永不重用）里的「永不重用」。另两条照样满足，却毫无用处——三个条件是合取（conjunctive）的，必须同时成立，缺一条保证就全没了。
  • 丢的是哪个安全目标？ 机密性（L1 §4.1 CIA 三要素）。而且没有任何算法被攻破，被破坏的是使用规则。
  • 说明了什么？ 密码强度不只是算法的属性。算法怎么用，决定了它的强度能不能保住。

课件由此引到 Lecture 5 的工作模式（mode of operation，规定怎样用分组密码去加密任意长消息的方法），说每一种工作模式都带一个一次性数（nonce，number used once，同一把密钥下只用一次的值）或初始化向量（initialisation vector，IV，加密开始时混进去的一个起始值），它们存在的唯一目的是保证同一把密钥下生成的密钥流永不重复。

这句课件原话只对 CTR（计数器模式）、OFB（输出反馈模式）这类把分组密码当流密码用、生成密钥流的模式成立。ECB（电子密码本模式，每个分组独立加密）没有 IV；CBC（密码分组链接模式，每个明文分组先异或上前一个密文分组再加密）的 IV 用来让相同的明文得到不同的密文（随机化），并不生成密钥流。

1.2这一讲要回答的问题

L2 的结论是：完美的保密存在，但一次一密的密钥和消息一样长、不能重用，几乎没法用（L2 §8.4）。实用的密码只能退一步：

密钥短（几十到几百位）、可以反复使用，并且在攻击者完全知道算法的前提下仍然破不了。

最后一条就是柯克霍夫原则（L2 §1.2）：只有密钥保密，算法公开。

课件给出的答案方向是 L2 双重置换（§9.2）里的那个想法：把一个弱操作重复很多次。但要补一个条件，这一讲的 4.5 会讲清原因：被重复的必须是非线性的操作。双重置换只是换位，换位叠多少次还是换位，字母频率原样保留；真正的分组密码重复的是带非线性代换的轮（round，每次重复的那一整套操作）。

2流密码与分组密码

L2 讲过给密码分类的第三个维度（L2 §1.3）：按怎么处理明文，分成流密码和分组密码。这一讲先把两者放在一起比，说明后面为什么几乎只讲分组密码。

2.1流密码

流密码（stream cipher）一次加密数据流的 1 位或 1 个字节。L2 的 Vernam 密码（§8.1）就是它的原型：如果密钥流真随机、又永不重用，它就是一次一密。

它的结构（课件第 5 页的框图）：密钥 K 送进一个伪随机字节生成器（pseudorandom byte generator，用确定的算法把短密钥扩展成一长串「看起来随机」的字节），生成密钥流（keystream）ki；每个明文字节 pi 和对应的 ki 异或，得到密文字节 ci = pi ⊕ ki。异或两次同一个值会抵消，所以解密是完全相同的操作：ci ⊕ ki = pi。

和一次一密相比，它把「等长的真随机密钥」换成了「由短密钥算出来的伪随机密钥流」。于是对它的设计要求（课件原列四条）都围绕「这串伪随机数能不能冒充真随机」：

  1. 密钥流在重复之前要有很长的周期（period，序列开始循环之前的长度）——一旦循环，就退化成 L2 那种会重复的 Vigenère 关键词（§7.2）；
  2. 统计上与真随机无法区分；
  3. 密钥要长到暴力破解（L2 §2.3）不可行，128 位是现在的实际下限；
  4. 双方只共享密钥，各自独立生成同一条密钥流。

用在哪里：数据连续到达、必须随到随处理的场合——语音和视频链路、无线协议，以及使用 ChaCha20（一种现代流密码）的 TLS 连接（Transport Layer Security，传输层安全协议，即 HTTPS 底下那层加密）。流密码快、代码少，等不及凑满一整块时是自然的选择。

2.2分组密码

分组密码（block cipher）把明文切成固定长度的分组（block），每个明文分组加密成一个等长的密文分组，典型长度是 64 位或 128 位。课件第 6 页的框图：b 位明文分组和密钥 K 一起进入加密算法，输出 b 位密文分组。

「出错时的影响」一行可以这样理解。

流密码一侧指的是同步流密码（synchronous stream cipher，密钥流只由密钥生成、与密文无关，2.1 的结构就是这种）：密文第 i 位只和明文第 i 位、密钥流第 i 位有关，传输中错了一位，解出来也只错这一位。

分组密码一侧：解密本身也是一个分组密码，同样满足雪崩效应，密文分组里任何一位都牵动解出的整个明文分组。所以在 ECB、CBC 这类直接解密密文分组的模式下，密文错一位，解出来的整个分组面目全非；CTR 这类模式只用分组密码生成密钥流、再与数据异或，错一位仍只错一位。

为什么后面几乎只讲分组密码：把分组密码放进合适的工作模式里运行（Lecture 5），它就能当流密码用；反过来理论上可行但不实用。所以一个强的分组密码两种用法都能给，绝大多数应用都建立在分组密码之上。DES、AES、Lecture 5 讲的全是分组密码。

3理想分组密码

3.1加密必须可逆

设分组长度为 n 位（本笔记里 n 只用来表示分组长度）。一个 n 位分组有 2n 种可能的取值，分组密码就是把这 2n 个明文分组映射到 2n 个密文分组。要能解密，映射必须可逆：每个明文分组对应一个不同的密文分组。课件用 n = 2 的两张表对比：

可逆（非奇异，nonsingular）不可逆（奇异，singular）
00 → 1100 → 11
01 → 1001 → 10
10 → 0010 → 01
11 → 0111 → 01
每个密文恰好出现一次，解密无歧义收到密文 01，可能来自 10 也可能来自 11，接收方无从判断，这根本不算密码

「可逆」在数学上就是一一对应（bijection）：2n 个输入、2n 个输出，两两配对，没有两个输入挤到同一个输出上。

3.2理想分组密码：任意一个一一映射

既然分组密码就是 2n 个分组之间的一个一一映射，最一般、最强的做法是：从所有可能的一一映射里任选一个，这个映射本身就是密钥。这叫理想分组密码（ideal block cipher）。

它强在哪：映射是任意挑的，没有任何公式、规律可循，同一个明文分组变成哪个密文分组完全由这张表决定。分析者手里没有任何可以利用的结构，能做的只有查表——而表正是密钥。

有多少把密钥：一一映射的个数，就是把 2n 个密文值排成一列的方法数，即 (2n)!。n = 2 时 4! = 24，n = 4 时 16! ≈ 2.09 × 1013。

易错permutation 的两个意思

课件说理想分组密码是 “any permutation of the 2n possible blocks”。这里的 permutation 指数学上的排列，即 2n 个取值之间的一一对应——它整体上是一张巨大的代换表，相当于把单表代换的字母表从 26 个字母换成了 2n 个分组。

后面 5.1 和 DES 里的「置换」（permutation，如 P 置换、初始置换）指的是另一件事：位的位置重排，每一位的值不变、只换位置，和 L2 的置换密码（§9）同类。

区分方法：看被打乱的是「取值」还是「位置」。

L2 的「置换」（transposition，重排字母的位置）与这里重排位的位置意义上的 permutation 是同一类操作，中文都叫置换；而理想分组密码说的 permutation 是在取值之间一一映射，本质是代换。

3.3密钥有多长

理想分组密码的密钥是整张映射表。要把它写下来，最直接的写法是按明文分组 0, 1, …, 2n − 1 的顺序，依次写出各自对应的密文分组：

  • 表有 2n 行（每个可能的明文分组一行）；
  • 明文那一列按固定顺序排，不用写，每行只写密文，n 位。

所以写下一把密钥需要

n · 2n 位(2)

代入 DES 的分组长度 n = 64：

64 × 264 = 270 位 = 267 字节 ≈ 1.48 × 1020 字节 ≈ 148 EB(3)

EB（exabyte，艾字节）是 1018 字节。148 EB 相当于大约 1.5 亿块 1 TB 的硬盘，而这只是一把密钥，收发双方还要各存一份、安全地传过去。这就是课件说「完全不实用」的原因。

n · 2n 不是「区分所有密钥的最少位数」

n · 2n 是把整张表直接写出来的长度，课件和教材都用它。

如果只问「给 (2n)! 把密钥各编一个号，号码最短要几位」，答案是 log2((2n)!)：n = 2 时约 4.58 位（对比直接写表的 8 位），n = 4 时约 44.25 位（对比 64 位），n = 64 时约为 n · 2n 的 97.7%。

两种算法差别不大，结论相同：大到不可行。考试按课件写 n · 2n。

3.4为什么不能把分组改小

密钥长度随 n 指数增长，那把 n 取小呢？n = 4 时密钥只要 64 位，完全能用。问题是这时每个分组只有 16 种取值，整个密码就是一个「16 个符号的单表代换」：同一个 4 位明文分组永远变成同一个 4 位密文分组，单表代换（L2 §4.1）那套频率分析原样适用。

所以两头都堵死了：n 大，密钥存不下；n 小，统计结构漏出来。现实中的每一个分组密码都是对理想分组密码的近似：分组足够大（64、128 位），密钥只有几十到几百位，用一个固定的、公开的算法从短密钥生成一个「看起来像随机挑的」一一映射。(264)! 个映射里，DES 的 56 位密钥只能选中其中 256 个。

课堂活动 1 解答：理想密码的密钥有多大

推导见 3.2–3.4，这里只列答案。

  • (a) n = 2：4! = 24 个可逆映射。
  • (b) n = 4：16! ≈ 2.09 × 1013 个。
  • (c) 写下一个映射要 n · 2n 位：n = 2 时 8 位，n = 4 时 64 位。
  • (d) n = 64：270 位 = 267 字节 ≈ 148 EB。

一句话：理想分组密码的密钥就是整张映射表，分组大到能抵抗统计分析时，这张表大到无法存储、分发和共享；把分组改小又退化成可被频率分析的单表代换，所以只能用短密钥去近似它。

4香农的两个目标：扩散与混淆

4.1统计结构是敌人

香农（Claude Shannon）在 1949 年的论文里指出：L2 里每一次成功的攻击都是同一个套路——明文有统计结构，密码保留了其中一部分，分析者利用了留下来的那部分。

密码漏到密文里的统计量
单表代换单字母频率，原封不动
Playfair双字母组频率，被压平但仍在
Vigenère每个密钥位置上的字母频率，外加重复的周期
置换密码字母频率完全保留，只是顺序变了
一次一密什么都不漏——也是唯一不可破的那个

由此得出香农的目标：让密文的统计特性与明文的统计特性无关。他提出两种挫败统计分析的方法：扩散（diffusion）和混淆（confusion）。此后的每一个分组密码，都是在尝试同时做到这两件事。

4.2扩散

扩散：把明文的统计结构摊薄到密文的长程统计（long-range statistics，跨越很多位置的统计关系）里——每一个明文位影响许多个密文位；反过来说，每一个密文位由许多个明文位共同决定。

香农自己的例子：把相邻的 t 个明文字母相加，得到一个密文字母（字母编号 a=0…z=25，同 L2）：

yj = ( Σi=1t mj+i ) mod 26(4)

mj+i 是第 j + i 个明文字母的编号，yj 是第 j 个输出字母的编号。现在每个输出字母依赖 t 个明文字母。（课件把求和的上下限漏写了，按上式理解。这个例子只演示扩散，本身没有密钥。）

例：t = 2，明文 seethe 的相邻两字母依次相加：s+e = 18 + 4 = 22→W，e+e = 8→I，e+t = 23→X，t+h = 26 mod 26 = 0→A，h+e = 11→L。同一个明文字母 e 参与了四个输出字母，四次都不同。

为什么这样能挫败频率分析：一个输出字母是 t 个明文字母之和，它的频率就是许多种明文组合的平均；平均会把分布拉平。按英文字母频率、并假设相邻字母互相独立来估算：

完全均匀时每个字母占 1/26 ≈ 3.85%。t = 2 时分布已接近平坦。分析者统计密文符号，几乎得不到明文的信息，因为没有一个密文符号只来自一个明文符号。

在现代分组密码里，扩散靠「置换（重排位的位置）之后再接一个函数」来实现，重复足够多次，一个输入位就能影响到每一个输出位。它可测的后果就是雪崩效应：明文改 1 位，密文应有大约一半的位跟着变。

易错光重排不是扩散

课件同一讲里有两种说法：“Rearranging alone is not diffusion”（第 11 页），以及 “Permutation … Provides DIFFUSION”（第 15 页）。正确的理解是：

  • 置换（重排位的位置）是实现扩散的手段，单独使用不产生扩散。 只重排、不组合，每个输出位仍然只来自一个输入位，0 和 1 的统计一点没变——L2 的置换密码就是这样，字母频率原样保留。
  • 置换必须和「把多个位组合起来」的函数（代换、加法、异或混合）交替、重复多轮，才真正把一个位的影响扩散到整个分组。

4.3混淆

混淆：让密文的统计特性与密钥取值之间的关系尽可能复杂——即使分析者掌握了密文的某些统计规律，密钥是以多么复杂的方式参与产生这些密文的，仍然让他推不出密钥。

做法是代换，尤其是复杂的非线性代换。非线性代换的典型实现是 S 盒（S-box，substitution box，一张固定的查找表：输入几位，查表得到几位输出，输入与输出之间没有简单的公式关系）。

为什么必须是非线性的：如果密钥和密文之间的关系很简单，一对已知的明密文就能直接把密钥解出来。最极端的例子是「密文 = 明文 ⊕ 密钥」。本讲起明文分组记 P、密文分组记 C，用密钥 K 加密写作 C = E(K, P)、解密写作 P = D(K, C)，即 L2 §1.1 的 Y = E(K, X)、X = D(K, Y)。拿到一对 (P, C)，K = P ⊕ C，一步就出来。关系越简单（越「线性」），越容易反解；4.5 会把「线性」讲清楚。

勘误课件第 12 页左栏的正文放错了位置

第 12 页左栏的标题是 “Diffusion attacks the plaintext link”，下面那段正文 “Even if the analyst can get some handle on the statistics of the ciphertext, the way in which the key was used to produce it is so complex that deducing the key remains difficult” 讲的是密钥怎样参与产生密文，描述的其实是混淆（几乎逐字来自教材对混淆的解释）。

左栏应有的内容是扩散：明文的统计规律被摊薄到密文的长程统计里。右栏 “Confusion attacks the key link” 没有问题。

4.4两者缺一不可

课件说这两行「值得背下来」：

怎么做隐藏的是哪条联系
扩散代换与置换，把明文的影响铺开明文与密文之间的关系
混淆由密钥驱动的复杂非线性代换密钥与密文之间的关系

一个看图的说法：攻击者想从密文出发，沿两条线往回走——一条通向明文（「密文统计 ← 明文统计」），一条通向密钥（「密文统计 ← 密钥」）。扩散切断前一条，混淆切断后一条。

两者都不能单独成事：

  • 只有扩散、没有混淆：明文被搅得很均匀，但密钥参与的方式简单，一两对已知明密文就能把密钥反解出来——泄露密钥。
  • 只有混淆、没有扩散：每个小单元各自被一张由密钥决定的复杂表代换，但单元之间互不影响，同样的明文单元永远变成同样的密文单元——单表代换就是这种情况，泄露明文结构（频率）。

所以每一个分组密码都两样都做，而且反复做。

4.5线性：为什么重复线性操作没用

线性（linear）在这里的意思是：每一个输出位都只是若干个输入位（和固定常数、密钥位）的异或。置换（每个输出位就是某一个输入位）、和密钥逐位异或、乘一个 0/1 矩阵，都是线性的。

线性有两个致命后果：

  1. 线性叠线性还是线性。 把两个线性操作接在一起，每个输出位仍然是输入位的异或组合，只是组合方式换了一种。所以把一个线性的轮重复 16 次、100 次，整体仍是一个线性变换，一点没有变强。L2 的双重置换比单次置换强，强的是「让手工拼词更难」，但在统计上它和单次置换一样，字母频率原样保留。
  2. 线性密码可以直接解方程。 若整个密码是线性的，每个密文位都能写成「明文位和密钥位的异或」的一个方程。拿到一对已知明密文，就得到 64 个关于 56 个未知密钥位的线性方程，用高斯消元（解线性方程组的标准方法）瞬间解出密钥。

S 盒不满足这种关系。拿 DES 的第一个 S 盒 S1 试一下。它输入 6 位、输出 4 位，查表时首尾两位定行、中间四位定列（查法见 6.4）；这里要用的四个值是 S1(000000) = 1110、S1(000001) = 0000、S1(000010) = 0100、S1(000011) = 1111，依次是 S1 第 0 行第 0 列的 14、第 1 行第 0 列的 0、第 0 行第 1 列的 4、第 1 行第 1 列的 15。

如果 S1 是「异或组合」，对任意输入 a、b 应有 S1(a ⊕ b) ⊕ S1(000000) = S1(a) ⊕ S1(b)。取 a = 000001、b = 000010：左边 S1(000011) ⊕ S1(000000) = 1111 ⊕ 1110 = 0001，右边 S1(000001) ⊕ S1(000010) = 0000 ⊕ 0100 = 0100，不相等。（6.4 的查表器里可以换别的 a、b 和别的 S 盒自己试。）

这就是课件结尾那句话的意思：只有被重复的操作是非线性的，重复才会让密码变强。

课堂活动 2 解答：混淆还是扩散？

题目：判断每个操作主要提供混淆、主要提供扩散，还是两者都有，各给一句理由。

操作判断理由
① 分组的每一位与轮密钥（round key，每一轮用的那份密钥，即 5.2 的子密钥）的一位异或混淆（很弱）它把密钥引入数据，作用在「密钥—密文」这条线上；但它是线性、逐位的，单用时混淆很弱，也完全没有扩散（每个输入位只影响一个输出位）
② 按固定表重排分组的 64 位扩散（单用无效）它改变位的位置，是扩散的手段；但单独使用只是换位，不改变 0/1 的统计，必须与非线性函数配合
③ 每 6 位一组，用固定的非线性 S 盒换成 4 位主要是混淆（也带一点扩散）S 盒提供非线性，是混淆的核心部件；它本身是固定公开的表，要与前一步异或进来的子密钥配合才构成混淆。每个输出位依赖 6 个输入位，所以也有局部的扩散
④ 把分组看作向量，乘一个固定的可逆矩阵扩散每个输出位依赖多个输入位；但它是线性的，不提供混淆（类似 L2 §5 点过名的 Hill 密码）
⑤ 把相邻 t 个明文字母相加，模 26扩散正是香农自己举的扩散例子
⑥ 用循环移位和压缩置换（从中挑出一部分位并重排）从主密钥（用户持有的那把密钥）派生各轮密钥两者都不直接提供这是密钥编排（从主密钥派生各轮密钥的算法），不作用在数据上；它让每轮用到的密钥位不同，间接为混淆服务（DES 的做法见 6.5）

④ 中的可逆矩阵（invertible matrix）是能求逆的矩阵，乘它的变换可以撤销，所以能用在加密里。

追问：只用操作 ② 重复很多次的密码，做不到什么、像 L2 的哪个密码？

多个固定置换接在一起仍是一个固定置换。它不依赖密钥（没有混淆），只移动位、不组合位（没有真正的扩散），位的统计原样保留。它就是 L2 的置换密码、双重置换——重复线性操作不增加强度。

5Feistel 结构

5.1乘积密码

问题已经清楚：要对大的 n 近似理想分组密码，又只能用容易实现的部件来搭。IBM 的 Horst Feistel 在 1973 年给出的方案是乘积密码（product cipher）：把两个或更多个简单密码依次执行，使最终结果比其中任何一个部件都强。部件只有两种：

部件做什么提供
代换
substitution		每个明文元素或元素组换成对应的密文元素或元素组混淆
置换
permutation		元素序列换成它的一个重排：不增、不删、不换，只调顺序扩散（须与代换配合，见 4.2）

这就是香农提议的实际落地：交替执行混淆和扩散。做一次很弱；做 16 次、每轮用不同的密钥，就得到一个五十年来没被实用的密码分析攻破的东西（DES 后来是被暴力穷举攻破的，见第 8 节）。它是 L2 双重置换想法的升级版：换成非线性的轮、并正确地重复。

5.2一轮 Feistel

记号：分组长 2w 位，切成左右两半，各 w 位。加密第 i 轮输出的左半、右半记作 LEi、REi（E 表示加密 encryption；解密那一侧记作 LDi、RDi），输入的明文就是 LE0、RE0。上图和课堂活动里把它们简写成 Li、Ri，是同一个东西。

记号图里的 n 指轮数

课件这张图和第 16、18 页文字里的 n 表示轮数（rounds 2 to n、Kn），与第 3 节里表示分组长度的 n 不是一回事。本笔记正文里轮数直接写数字（DES 是 16）。

照着图看一轮做了什么：

  1. 右半 REi−1 兵分两路：一路原样往下，成为下一轮的左半；另一路送进轮函数（round function）F，和本轮的子密钥（subkey）Ki 一起算出一个 w 位的值。这里的轮函数专指 Feistel 每轮作用在右半、带子密钥的这个函数 F；L2 双重置换（§9.2）一节里的「轮函数」泛指一整轮做的那套变换。
  2. 这个值和左半 LEi−1 异或，结果成为下一轮的右半。
  3. 两半交换位置（图中交叉的两条线）。

写成两行式子：

LEi = REi−1,  REi = LEi−1 ⊕ F(REi−1, Ki)(5)

课件说「两行，这就是整个密码结构」——其余全是选择：F 长什么样、子密钥怎么生成、重复多少次。

用 5.1 的两个部件来读这一轮：

  • 代换作用在左半上：左半被异或上一个「由右半和密钥决定」的值；
  • 置换就是两半的交换。

每一轮的结构完全相同，只是子密钥 Ki 不同。子密钥由主密钥（master key，用户实际持有的那把密钥）经密钥编排（key schedule，从主密钥派生各轮子密钥的算法）生成。全部轮做完后，再把两半交换一次，得到密文；这一步的作用在 5.4 讲。

5.3手算一轮

课堂活动 3 的玩具密码：分组 8 位，左右各 4 位；轮函数

F(R, K) = (R ⊕ K) 在 4 位内循环左移 1 位(6)

循环左移 1 位（rotate left）：所有位往左挪一格，最左边挤出去的那一位补到最右边。例：1011 → 0111。

明文 1011 0110，即 L0 = 1011、R0 = 0110；子密钥 K1 = 1101、K2 = 0011。第 1 轮按三步走：

1算 F(R0, K1)：R0 ⊕ K1 = 0110 ⊕ 1101 = 1011，循环左移得 0111。
2新左半直接抄旧右半：L1 = R0 = 0110。
3新右半 = 旧左半 ⊕ F：R1 = L0 ⊕ 0111 = 1011 ⊕ 0111 = 1100。

第 1 轮输出 L1R1 = 0110 1100。自查习惯：新左半一定等于旧右半，不用算；容易错的只有 F 和最后那次异或。

课堂活动 3 解答：跑两轮，再撤销一轮

(a) 第 1 轮：F(R0, K1) = 0111，L1 = 0110，R1 = 1100（过程见上）。

(b) 第 2 轮：R1 ⊕ K2 = 1100 ⊕ 0011 = 1111，循环左移仍为 1111；L2 = R1 = 1100，R2 = L1 ⊕ 1111 = 0110 ⊕ 1111 = 1001。得 L2R2 = 1100 1001（题目说这是做最终交换之前的密文）。

(c) 只用 L2、R2、K2 和同一个 F（不许求 F 的逆），恢复 L1、R1：

  • R1 直接读出：加密时 L2 = R1，所以 R1 = L2 = 1100；
  • R1 有了，就能正向再算一次 F(R1, K2) = F(1100, 0011) = 1111；
  • 加密时 R2 = L1 ⊕ 1111，两边再异或 1111：L1 = R2 ⊕ 1111 = 1001 ⊕ 1111 = 0110。

恢复出 L1R1 = 0110 1100，与 (a) 一致。整个过程 F 只被正向计算过。

5.4解密：同一个算法，密钥倒序

撤销一轮的通式。 课堂活动 3(c) 的做法对任何一轮都成立。加密的两行式子是 LEi = REi−1、REi = LEi−1 ⊕ F(REi−1, Ki)。倒过来：

REi−1 = LEi,  LEi−1 = REi ⊕ F(LEi, Ki)(7)

第一式直接读出旧右半；有了它就能正向算出 F(REi−1, Ki)，即 F(LEi, Ki)；再异或一次把它从 REi 里消掉，就得到旧左半。用到的只是「同一个值异或两次就抵消」（X ⊕ X = 0），从头到尾没有求过 F 的逆。

核心Feistel 结构不要求 F 可逆

这就是课件强调的结论：Feistel 结构不要求 F 可逆。

例：把 F 换成不可逆的逐位与，照样能解密

把课堂活动 3 的 F 换成一个明显不可逆的函数 F(R, K) = R AND K（逐位「与」：两位都是 1 才得 1）。取 K = 0011，R = 0110、0010、1110 三个不同输入都输出 0010——知道输出根本猜不回输入。用同样的明文和子密钥跑两轮：第 1 轮 F = 0110 AND 1101 = 0100，得 L1R1 = 0110 1111；第 2 轮 F = 1111 AND 0011 = 0011，得 L2R2 = 1111 0101。按撤销通式倒回去：F(1111, 0011) = 0011，L1 = 0101 ⊕ 0011 = 0110、R1 = 1111；F(0110, 1101) = 0100，L0 = 1111 ⊕ 0100 = 1011、R0 = 0110。明文完整还原。

为什么全部轮做完要再交换一次。 有了最后这次交换，解密就能用和加密一模一样的算法：把密文当输入，子密钥按 K16, K15, …, K1 的倒序送进去即可（以 16 轮为例）。推导如下。

解密正确性的推导（以 16 轮为例）

加密做完第 16 轮后交换两半，密文是 RE16 ‖ LE16（‖ 表示把两段位串前后拼接）。

解密用同一个算法，输入就是这段密文：LD0 = RE16，RD0 = LE16。第 1 轮用 K16：

LD1 = RD0 = LE16 = RE15

最后一个等号用的是加密第 16 轮的 LE16 = RE15。

RD1 = LD0 ⊕ F(RD0, K16)
= RE16 ⊕ F(RE15, K16)
= [LE15 ⊕ F(RE15, K16)] ⊕ F(RE15, K16)
= LE15

第三行把加密第 16 轮的 RE16 = LE15 ⊕ F(RE15, K16) 代了进去，第四行是同一个值异或两次抵消。

所以解密第 1 轮的输出 LD1 ‖ RD1 = RE15 ‖ LE15，正好是加密第 15 轮输出的左右互换。同样的论证逐轮重复：解密第 i 轮输出 RE16−i ‖ LE16−i。16 轮后得到 RE0 ‖ LE0，最后那次交换把它变回 LE0 ‖ RE0，即明文。

整个推导只用了 X ⊕ X = 0，没有用到 F 的任何性质。

用玩具密码验证一遍（两轮，加最终交换）：加密得 L2R2 = 1100 1001，交换后密文为 1001 1100。把它原样送进加密算法，密钥倒序：

  • 第 1 轮用 K2 = 0011：F(1100, 0011) = 1111，新左半 1100，新右半 1001 ⊕ 1111 = 0110；
  • 第 2 轮用 K1 = 1101：F(0110, 1101) = 0111，新左半 0110，新右半 1100 ⊕ 0111 = 1011；
  • 最终交换：1011 0110，回到明文。

玩具 Feistel 步进器：逐轮加密、撤销一轮、倒序解密

与课堂活动 3 同一个玩具密码：左右各 4 位，F(R, K) = (R ⊕ K) 循环左移 1 位。一轮一轮往下走；「撤销一轮」只用当前的 Li, Ri, Ki 和正向的 F。把 F 换成不可逆的 AND 再试一遍，照样能解。

这带来什么好处。 同一套硬件或软件既加密又解密，只是密钥编排倒着跑，实现成本减半——这在 1975 年极其重要，在今天的低功耗受限设备上也仍然重要。更重要的是第二条：F 不必可逆，设计者就可以只为强度去设计 F（例如 DES 的 S 盒 6 位进 4 位出，本身就是多对一的）。

课后作业 Task 1 解答：第三轮与三轮解密

题目：同一个 F、同一个 L0R0 = 1011 0110、K1 = 1101、K2 = 0011，再用 K3 = 1010 跑第三轮，然后把三轮全部解密，确认还原出明文。

第 3 轮：R2 ⊕ K3 = 1001 ⊕ 1010 = 0011，循环左移得 F = 0110；L3 = R2 = 1001，R3 = L2 ⊕ 0110 = 1100 ⊕ 0110 = 1010。得 L3R3 = 1001 1010。

逐轮撤销（Ri−1 = Li，Li−1 = Ri ⊕ F(Li, Ki)）：

  • 撤销第 3 轮：F(1001, 1010) = 0110，L2 = 1010 ⊕ 0110 = 1100，R2 = 1001；
  • 撤销第 2 轮：F(1100, 0011) = 1111，L1 = 1001 ⊕ 1111 = 0110，R1 = 1100；
  • 撤销第 1 轮：F(0110, 1101) = 0111，L0 = 1100 ⊕ 0111 = 1011，R0 = 0110。

还原出 1011 0110。

5.5六个设计选择

一个 Feistel 网络具体长什么样，取决于六个选择：

选择取舍
分组长度
block size		越大越安全，但越慢。64 位是传统，128 位是现在的标准
密钥长度
key size		越长越能抵抗暴力破解，但可能变慢。56 位已不够，128 位是下限
轮数
number of rounds		Feistel 密码的精髓：一轮不够安全，多轮让安全性递增。16 轮很典型
子密钥生成算法
subkey generation，即 5.2 说的密钥编排		越复杂，密码分析越难
轮函数 F
round function		越复杂，通常越能抵抗密码分析；这是密码的核心
执行速度

但它的设计过程和 S 盒的设计准则是保密的（见 8.2），所以还算不上 L1 的开放设计原则（§7.3 十三条设计原则）——那要求设计理由也公开、接受审查。完整做到开放设计，要等到 AES 的公开竞赛（L4 §1.2）。今天不该再用 DES，原因在 8.1。

6.2总体结构

左边是数据通路，从上往下读：

  1. 初始置换（initial permutation，IP）：按一张固定的表把 64 位明文重新排位；
  2. 排好的 64 位分成左右各 32 位，经过 16 轮 Feistel，每轮用一个 48 位子密钥；
  3. 16 轮后做一次 32 位交换（两半互换），也就是 5.4 里那次「最后再交换一次」；
  4. 逆初始置换（IP⁻¹）把位的顺序排回去，得到 64 位密文。

右边是密钥编排，6.5 讲。解密走完全相同的通路，子密钥倒序使用。

IP 和 IP⁻¹ 是固定的、公开的、与密钥无关的。攻击者拿到密文，自己做一次 IP 就能剥掉它，所以它们对安全毫无贡献——这是课堂活动 4 D 项的答案。

6.3轮函数 F 的内部

课件只说 DES 每轮是一个 Feistel 轮，没讲 F 的内部。教材与标准里 F 由四步组成：

  1. 扩展置换 E（expansion permutation）：32 位 → 48 位。把 32 位分成 8 组、每组 4 位，每组再向左右两边的相邻组各借 1 位（首尾两组互相借，绕成一圈），扩成 6 位。于是有 16 个位被用了两次。
  2. 与子密钥异或：48 位和本轮的 48 位子密钥 Ki 逐位异或——密钥只在这一步进入数据。
  3. 8 个 S 盒：48 位按顺序切成 8 组、每组 6 位，第 j 组送进第 j 个 S 盒，每个 S 盒输出 4 位，共 8 × 4 = 32 位。
  4. 置换 P：按固定表重排这 32 位，得到 F 的输出。

每一步对应第 4 节的扩散或混淆：

  • S 盒是 DES 里唯一的非线性部件（E、P、IP、异或、移位全是线性的），是混淆的核心部件。S 盒本身是一张固定公开的表、不含密钥，它与前一步异或进来的子密钥配合才构成混淆：子密钥决定 S 盒查到哪一格，S 盒让密钥与输出之间的关系变成非线性的。AES 的 S 盒同理，见 L4 §3.3。
  • E 和 P 负责扩散：E 让边界上的 16 个位同时进入两个 S 盒，一个输入位一变就同时扰动两个 S 盒；P 把每个 S 盒的 4 个输出位分散送往下一轮的不同 S 盒。几轮下来，一个位的影响就铺满全部 64 位——这正是第 7 节实测到的。

E、S 盒、P 的完整表格课件没有给，见 FIPS 46-3 或教材附录。考试若考查表，题目会给出用到的表；要会的是下面的查表方法。

6.4S 盒查表

每个 S 盒是一张 4 行 × 16 列的表，格子里是 0–15 的数（即 4 位输出）。6 位输入 b1b2b3b4b5b6（b1 是最左边一位）这样拆：

  • 行号 = 首尾两位拼起来 b1b6，取值 0–3；

  • 查到的数写成 4 位二进制，就是输出。

6.5密钥编排

DES 从 64 位密钥生成 16 个 48 位子密钥（对照上面总体结构图的右半边）：

  1. 置换选择 1（permuted choice 1，PC-1）：64 位 → 56 位。丢掉 8 个奇偶校验位，其余 56 位按固定表重排，分成左右两个 28 位的半区 C0、D0（这里的 C、D 是密钥寄存器的两半，与密文 C 无关）。
  2. 每轮循环左移：第 i 轮把 C、D 各自循环左移 1 位或 2 位——第 1、2、9、16 轮移 1 位，其余各轮移 2 位。16 轮累计恰好移 28 位，转回原位，所以解密时可以用循环右移按倒序生成同样的子密钥。
  3. 置换选择 2（PC-2，课件叫压缩置换 compression permutation）：从移位后的 56 位里按固定表选出 48 位并重排，作为本轮子密钥 Ki。

因为每轮移位后各个主密钥位落在不同的位置上，PC-2 每轮挑中的是不同的一组主密钥位，16 个子密钥与主密钥的关系各不相同。

勘误「每轮丢掉不同的 8 位」指的是丢掉不同的主密钥位

课件说 “the compression drops a different eight bits each time”。准确地说：PC-2 是一张固定的表，它丢掉的永远是 56 位寄存器 C ‖ D 里同样 8 个位置（第 9、18、22、25、35、38、43、54 位）。每轮变化的是哪些主密钥位正好移到了这 8 个位置上。

另外课件写 “Permute the 56-bit key”，严格地说 PC-1 的输入是 64 位密钥，它同时完成「去掉校验位」和「重排」两件事，输出 56 位。

7雪崩效应

7.1定义与实测

雪崩效应（avalanche effect）：任何加密算法都希望具备的性质——明文或密钥的微小改变，应当引起密文的显著改变。它是「扩散与混淆做到了没有」的可测指标：

  • 改明文的 1 位（密钥不变）：两段密文应有大约一半的位不同。这是扩散的可测后果——一个明文位影响了每一个密文位。
  • 改密钥的 1 位（非校验位，明文不变）：同样应有大约一半的位不同。课件称之为「混淆性质的实测」——密钥的微小改动不能造成一个小而可追踪的密文变化。（教材把这两种都叫雪崩效应，不区分扩散与混淆。）

DES 的 64 位密钥里有 8 位是奇偶校验位（6.1），算法不用它们，翻转它们密文不变；所以这里的「改密钥的 1 位」指 56 个有效位之一。

上图是用 DES 实际跑出来的（本页打开时由页面里的 DES 现算）：随机取 1000 组密钥与明文，每组只翻转 1 位（改密钥时翻转的是非校验位），统计每一轮结束时两次运行的 (Li, Ri) 有多少位不同，取平均。第 0 轮指刚做完初始置换、还没进第 1 轮时。三角形是课件第 21 页的柱状图数值，课件自己注明是「示意」（illustrative progression）。

读图：

  • 改明文 1 位：第 3 轮平均约 22 位不同（课件说「三轮后约 21 位」，吻合），第 5 轮起稳定在 32 位附近，此后一直在 32 上下。
  • 改密钥 1 位：走势几乎一样，最后也停在约 32 位。

7.2为什么正好是一半

「两段密文差一半的位」是两段毫不相关的随机位串会有的样子：两段独立随机的 64 位串，每一位相同、不同的概率各 1/2，所以不同的位数平均为

64 × 12 = 32(8)

它的波动（二项分布的标准差）是 √64 × ½ × ½ = 4，所以单次实测落在 28–36 附近都正常：7.1 里教材那组单次数据从第 4 轮起在 29–37 之间起伏，就是这种随机波动；图中是 1000 次的平均，波动被平均掉，所以第 5 轮后几乎是一条平线。

所以「差约一半」的含义是：看两段密文，分不出它们来自只差一位的两段明文，就像两段无关的随机串。差得太少（如只差几位）不行，差得太多也不行——若总是差远多于 32 位，例如 60 位，那把一段密文整体取反就和另一段很接近，反而又暴露了联系。

7.3没有雪崩会怎样

没有雪崩，相似的明文就产生相似的密文。分析者可以加密自己的猜测、比较密文有多接近、朝着答案一步步调整，把穷举搜索变成有方向的搜索。雪崩效应抹掉了攻击者能顺着往上爬的每一个「坡度」，让暴力破解成为唯一的选择。

课后作业 Task 3 解答：没有雪崩时，不找密钥也能读明文

题目：一个 64 位分组密码完全没有雪崩——改明文 1 位，密文恰好只变 1 位。描述一种不求密钥就恢复明文的攻击。

思路：没有雪崩意味着「明文第 i 位一变，密文只有某个固定的第 j 位跟着变」，即存在一个固定的位对应关系。用选择明文攻击（L2 §2.1 四种攻击模型）把它测出来：

  1. 请对方加密全 0 明文，得 C0 = E(K, 0)；
  2. 对 i = 1, …, 64，请对方加密「只有第 i 位是 1」的明文 ei，看 E(K, ei) 与 C0 在哪一位不同，记下「明文第 i 位 ↔ 密文第 j 位」；
  3. 拿到要破的密文 C，算 C ⊕ C0：其中为 1 的密文位 j，对应的明文位 i 就是 1，其余为 0。于是读出明文。

一共 65 次选择明文加密，全程不碰密钥。只有已知明文时，也能用多组明密文对逐步建立这个对应关系。

这个对应关系对所有明文都成立：可以证明，「每改 1 位明文、密文恰好变 1 位」的一一映射只能是「把位重新排列、再异或一个固定值」，即 C = π(P) ⊕ C0（π 表示那个固定的位重排），所以第 3 步的读法总是对的。

8.2算法本身

与密钥形成对照的是算法本身：学术界、工业界和敌对政府公开分析了它 25 年，没有发现实用的结构性破解。

差分密码分析（differential cryptanalysis）：选一批明文对，让每对之间有特定的差异（异或值），观察这些差异经过各轮后怎样传播到密文，从统计偏差里推出子密钥。它在 1990 年前后由 Biham 与 Shamir 公开发表，结果发现 DES 早就对它有抵抗力：IBM 的设计者在 1974 年前后就已掌握这种技术，并据此调整了 S 盒。1992 年他们对完整 16 轮 DES 的差分攻击需要 247 个选择明文，运算量低于穷举，但这么多选择明文在现实中拿不到（与轮数的关系见 9.1）。

S 盒的疑云：S 盒的设计准则当年是保密的，多年来人们怀疑里面藏着后门（back door，设计者故意留下的、只有自己知道的破解捷径）。历史给出了相反的答案：保密掩盖的是一项长处，不是弱点。

课件的结论：DES 败于老化，不是败于设计错误。

补充DES 对线性分析没有专门抵抗

课件在讲轮函数设计时说「S 盒的选择使差分和线性密码分析都不优于穷举」（见 9.2），作为一般设计原则没错，但 DES 只做到了差分这一半：它的 S 盒只针对差分分析设计过。

线性密码分析（linear cryptanalysis）找明文、密文、密钥的某些位之间以略偏离 1/2 的概率成立的线性（异或）关系，收集大量已知明密文对，从统计偏差里估出密钥位。Matsui 1993 年提出线性分析（约 247 个已知明文），1994 年改进到约 243 个已知明文，并用 12 台工作站约 50 天实际恢复出 DES 密钥——运算量低于穷举的 255，在实验室里可行。但 243 对、每对 8 字节，单是已知明文就有约 70 TB，而且必须在同一把密钥下收集，实战中拿不到。所以「没有实用的结构性弱点」这句话仍然成立。

8.3计时攻击与侧信道

侧信道攻击（side-channel attack）不攻击算法的数学，而是从实现的物理表现里偷信息。

  • 计时攻击（timing attack）：不同的密钥、不同的输入，让运算花的时间略有不同；测量足够多次运算的耗时，就能推出密钥。
  • 按功耗推断密钥是另一类侧信道，叫功耗分析（power analysis）；课件把它和计时攻击写在了一句话里。

计时攻击更多与公钥算法联系在一起，但对称算法的实现同样可能中招（如 AES 软件实现里查表时间随缓存命中而变）。关键在于：缺陷在实现，不在算法。教材对 DES 本身的评价是它看起来对计时攻击相当有抵抗力。

8.4密钥长度是保质期

这一讲最能推广的一课：一个算法可以是正确的，却仍然会过期。 选密钥长度时，问的不是「它安全吗」，而是「考虑到硬件每年都在变便宜、数据可能需要保护几十年，它还能安全多久」。

这和 L2 的计算安全（§2.2 无条件安全与计算安全）是同一件事：破解时间要超过信息的有效期。也是 L1 讲的相称性原则（§2.2 安全是买来的，不是达到的）：对着资产的价值和威胁的能力，决定花多少成本去防。

9分组密码设计的三个杠杆

从 Feistel 至今，分组密码的设计原则没有变过。5.5 里的六个选择中，设计者真正在调的是三个杠杆：轮数、轮函数 F、密钥编排。

9.1轮数

轮数越多，密码分析越难，哪怕轮函数 F 相对较弱。

设计者实际用的准则：选够轮数，使任何已知的密码分析攻击都比简单的暴力穷举更费力。 这是一条干净诚实的标准——如果最聪明的已知攻击还不如把钥匙挨个试一遍，这个密码就没有值得挖掘的结构。

DES 是现成的例子。按教材 4.5 节的口径（差分分析约需 255.1 次运算，暴力穷举平均 255 次），16 轮时差分分析不比穷举省力。按攻击文献的数字：Biham 与 Shamir 1992 年对完整 16 轮的差分攻击只需 247 个选择明文，Matsui 1994 年的线性分析只需约 243 个已知明文（8.2），运算量都低于穷举，只是需要的数据多到不实用。

所以 16 轮的意义是：在设计者当年已知的差分分析下够用。课件对轮数只说了「16 而不是 8」。

这也解释了课堂活动 4 的 A 项（16 轮加到 32 轮）为什么几乎没用：DES 的瓶颈在 56 位密钥——结构性攻击都要海量明文、不实用，而穷举是实用的（8.1）。加轮数改进的是本来就不是瓶颈的那一边，穷举的代价一点没变。课件的原话：“Good security engineering means finding the binding constraint, not improving whatever is easiest to improve.”——好的安全工程是找到起决定作用的那个约束，而不是改进最容易改进的东西。

9.2轮函数 F

F 是 Feistel 分组密码的心脏，它提供混淆。F 越非线性，任何密码分析都越难。四条准则：

  1. 非线性：F 要尽可能非线性。线性的 F 会让整个密码写成一个线性方程组直接解出来，即 4.5 讲的失败。
  2. 严格雪崩准则（strict avalanche criterion，SAC）：任何一个输入位改变时，每一个输出位改变的概率都应为 1/2。这是把雪崩效应精确化，落到轮函数（或 S 盒）这一级。
  3. 位独立准则（bit independence criterion，BIC）：任何一个输入位改变时，任意两个输出位的变化应当彼此独立。否则输出位之间的相关性会给分析者一个统计抓手。
  4. 抵抗已知攻击：S 盒的选择要让差分和线性密码分析都不优于穷举。真正的设计工作大多花在这里。（DES 只做到了差分这一半，见 8.2 的说明。）
考点SAC 与 BIC：课件说「值得记住的两个缩写」

课件说 SAC 和 BIC 是「值得记住的两个缩写」，两者都是「输出应该看起来随机」这句话的精确、可测试的版本。两者的区别在于看几个输出位：SAC 看单个输出位各自翻转的概率，BIC 看一对输出位之间是否相关。

9.3密钥编排与弱密钥

任何 Feistel 密码都要从主密钥为每一轮生成一个子密钥。总的希望是：推出单个子密钥、以及从子密钥倒推主密钥，都尽可能难。好的密钥编排要满足：

  • 知道一部分密钥或子密钥位，不应能推出很多其他子密钥位；
  • 主密钥位与子密钥位之间也满足 SAC 和 BIC；
  • 没有「弱」的密钥——不存在让各轮子密钥相同或关系简单的密钥。
误区准则不要求「知道一个完整子密钥也推不出主密钥」

误：好的密钥编排要保证，知道一个完整的子密钥，就推不出主密钥和其他子密钥。

正：准则只要求知道一部分位时推不出很多其他位。那条更强的要求，DES 和 AES 都不满足：

  • DES 的一个 48 位子密钥就是主密钥 56 个有效位里的 48 位，剩下 8 位再穷举 28 = 256 次即得主密钥；
  • AES 的密钥扩展按设计就是可逆的，AES-128 知道一把完整轮密钥就能推出全部轮密钥和主密钥（L4 §9.3）。

DES 的做法见 6.5：移位量逐轮不同、压缩置换每轮挑中不同的主密钥位，没有两个子密钥与主密钥的关系相同。

但它的简单留下了一个真实且有点尴尬的后果——弱密钥（weak key）。DES 有 4 个弱密钥：它们使 C0、D0 各自全 0 或全 1，循环移位后不变，于是 16 个子密钥完全相同。解密是「同一算法、子密钥倒序」，而倒序后还是同样 16 个子密钥，所以加密等于解密，用弱密钥加密两次就回到明文：E(K, E(K, P)) = P。

另有 6 对半弱密钥（semi-weak key pairs）：一对中的两个密钥 K、K′ 生成的子密钥序列互为倒序，于是一个密钥的加密等于另一个的解密：E(K′, E(K, P)) = P。注意是两个不同的密钥各加密一次，同一个半弱密钥连加两次并不还原。

4 个弱密钥与 1 对半弱密钥（十六进制，含校验位）

弱密钥：0101010101010101、FEFEFEFEFEFEFEFE、E0E0E0E0F1F1F1F1、1F1F1F1F0E0E0E0E。

半弱密钥对之一：01FE01FE01FE01FE 与 FE01FE01FE01FE01。

只有 16 个，随机选到的概率约 16/256，生成密钥时检查一下就能避开。

10DES 之后

10.1双重 DES 与中间相遇攻击

56 位不够，最直接的补救是用两把独立的 56 位密钥加密两次，称双重 DES（2DES）：

C = E(K2, E(K1, P))(10)

这里和 10.2 的 K1、K2、K3 是几把独立的 56 位 DES 密钥，不是 5.3 里 Feistel 第 1、2 轮的子密钥。两把密钥合起来 112 位，看起来暴力破解要 2112 次。课件说直觉的答案是错的：中间相遇攻击（meet-in-the-middle attack，MITM）把代价降到约 257 次。

关键观察：从明文往前加密一层，和从密文往回解密一层，会在中间值 X 处相遇：

X = E(K1, P) = D(K2, C)(11)

于是不必同时猜两把密钥，可以分开猜。设攻击者有一对已知的明密文 (P, C)：

1对全部 256 个可能的 K1，计算 X = E(K1, P)，连同 K1 存进一张表，按 X 排序；
2对全部 256 个可能的 K2，计算 D(K2, C)，到表里查有没有相同的 X；
3每查到一次相同，就得到一个候选密钥对 (K1, K2)；
4用第二对已知明密文 (P′, C′) 检验候选：E(K2, E(K1, P′)) = C′ 才是真密钥。

代价：

  • 运算量：两个阶段各 256 次 DES，共 2 × 256 = 257 ≈ 1.44 × 1017 次，只比破单 DES 多一倍；
  • 存储量：一张 256 行的表，每行至少存一个 64 位的 X，约 576 PB（1 PB = 1015 字节）。存储是这个攻击真正的门槛，但它不改变运算量的数量级。

为什么要第二对：两把密钥共 2112 种组合，而 64 位分组只有 264 种密文。给定 P，大约有 2112/264 = 248 个密钥对恰好都把它加密成 C，其中只有一个是真的，其余是误报。每个误报碰巧也通过第二对检验的概率是 2−64，所以第二对之后剩下的误报约 248 × 2−64 = 2−16 个，基本只剩真密钥。

中间相遇攻击：8 位密钥的玩具双重加密

玩具分组密码 E：12 位分组、8 位密钥、4 轮 Feistel（F 查一张固定的 6→6 表，由 DES 的 S₁、S₂ 拼成），全部轮后再交换一次。双重加密 C = E(K2, E(K1, P)) 名义上有 16 位密钥。下面真的跑一遍正向表 + 反向查找，并可以用 216 次暴力穷举核对。

所以 2DES 从未部署：多花一倍时间，只换来一位的安全增量。课后作业 Task 2（写出中间相遇攻击的步骤、运算量与存储量，并说明三密钥 3DES 为什么不会被同样降级）的答案就是本节的四步加上 10.2 的一句话。

10.2三重 DES

三重 DES（3DES，Triple DES）用三次 DES 运算，按「加密—解密—加密」（E–D–E）排列：

C = E(K3, D(K2, E(K1, P)))(12)

为什么中间一步是解密：令三把密钥相等，中间的解密正好抵消第一次加密，剩下单次 DES，C = E(K1, P)。于是 3DES 硬件可以向后兼容（backward-compatible）单 DES，与只支持 DES 的老设备互通。这是纯粹的工程考虑，没有密码学意义。（其实不必三把都相等：只要 K1 = K2 或 K2 = K3，相邻的一加一解就抵消，整体退化成用剩下那把密钥的单 DES。）

为什么三把独立密钥时中间相遇攻击不灵：中间相遇只能把三层劈成「一层对两层」。一侧枚举 K1 只要 256 次，另一侧却要同时枚举 K2 和 K3，即 2112 次。总代价约 2112，所以三密钥 3DES 的有效安全约 112 位（名义密钥 3 × 56 = 168 位）。

它的代价与结局：运算量是单 DES 的三倍，分组仍是 64 位，速度慢；NIST 已禁止在 2023 年底之后用它加密新数据（解密旧数据仍允许）。课件说 3DES 是「用三倍的工作量换两倍的密钥」——这里的「两倍」指有效安全 112 位是 56 位的两倍。

还有一种双密钥 3DES：K3 = K1，名义 112 位，但存在已知明文攻击，有效强度约 80 位，同样已被淘汰。

AES（Advanced Encryption Standard，高级加密标准）是 Lecture 4 的主题。课件从这条演进里提炼的规律：一个密码老了，应对办法很少是给它打补丁——2DES 失败，3DES 只是权宜之计，真正的答案是通过公开竞赛选出一个全新的设计。

课后作业 Task 4 解答：AES 用的是什么结构

AES 不是 Feistel 密码，用的是代换—置换网络（substitution–permutation network，SPN）：每一轮对整个分组同时做代换（S 盒）和置换/混合，而不是像 Feistel 那样每轮只改一半。

对解密的后果：SPN 没有 Feistel 那种「正向算 F 再异或抵消」的机制，解密必须把每一步逆着做一遍（逆 S 盒、逆移位、逆混合，轮密钥倒序加回）。所以 AES 的 S 盒和每一步变换都必须可逆，解密算法也和加密不完全相同。这与 Feistel「F 不必可逆、加解密同一套电路」正好相反。Lecture 4 详讲。

11六条结论

课件结尾的六条，每条后面是它在本笔记里的位置：

  1. 理想分组密码需要 n × 2n 位的密钥，64 位分组时是 148 EB。每一个实际的密码都是对它的近似。（3.3）
  2. 扩散隐藏明文与密文之间的联系；混淆隐藏密钥与密文之间的联系。两者都要、而且反复做，否则都不起作用。（4.4）
  3. 只有被重复的操作是非线性的，重复才让密码变强。线性叠线性仍是线性。（4.5）
  4. Feistel 一轮就两行：LEi = REi−1，REi = LEi−1 ⊕ F(REi−1, Ki)。要能手算一轮、手动撤销一轮。（5.3）
  5. F 从来不必可逆。正是这份自由，让设计者可以只为强度去设计 F。（5.4）
  6. DES 败于老化，不是败于设计错误。密钥长度是保质期，选择它是一种风险判断。（8.4）

本讲速记

  • 两次一密：c1 ⊕ c2 = p1 ⊕ p2；一次一密三条件是合取的；没有算法被破，被破的是使用规则 → 课件：工作模式带 nonce / IV 防密钥流重复（只对 CTR、OFB 这类流密码式模式成立）。
  • 流密码：逐位/逐字节与伪随机密钥流异或；要求周期长、与真随机不可区分、密钥 ≥128 位。分组密码：固定长度分组，等长输出，典型 64/128 位。坏 1 位：同步流密码只坏 1 位；分组密码在 ECB/CBC 下坏整个分组（CTR 下只坏 1 位）。分组密码配工作模式可当流密码用。
  • 分组密码必须可逆（一一映射）。理想分组密码 = 任选 2n 个分组间的一个一一映射，密钥数 (2n)!，写下一把密钥要 n · 2n 位；n = 64 时 270 位 ≈ 148 EB。n 小又退化成单表代换 → 只能近似。
  • 扩散：每个明文位影响许多密文位，隐藏明文—密文联系；靠置换＋函数、多轮。香农例 yj = (Σi=1t mj+i) mod 26。光重排不是扩散。
  • 混淆：密文统计与密钥的关系尽量复杂，隐藏密钥—密文联系；S 盒提供非线性，是混淆的核心部件，与异或进来的子密钥配合才构成混淆。只有扩散 → 泄露密钥；只有混淆 → 泄露明文结构。
  • 线性 = 输出位是输入位的异或组合；线性叠线性仍线性；线性密码可直接解方程。重复必须用非线性操作。
  • 乘积密码：交替代换（混淆）与置换（扩散），多轮重复。
  • Feistel：LEi = REi−1，REi = LEi−1 ⊕ F(REi−1, Ki)；全部轮后再交换一次。撤销一轮：REi−1 = LEi，LEi−1 = REi ⊕ F(LEi, Ki)。解密 = 同一算法、子密钥倒序；F 不必可逆。玩具例 1011 0110 → 第 1 轮 0110 1100 → 第 2 轮 1100 1001 → 第 3 轮（K3=1010）1001 1010。
  • 六个设计选择：分组长度、密钥长度、轮数、子密钥生成、轮函数 F、执行速度（教材另有「便于分析」）。
  • DES：64 位分组、56 位有效密钥（64 位含 8 个校验位）、16 轮、48 位子密钥、1977 年。IP → 16 轮 → 32 位交换 → IP⁻¹。IP/IP⁻¹ 对安全无贡献。
  • DES 的 F：E 扩展 32→48 → ⊕Ki → 8 个 S 盒各 6→4 → P 置换 32→32。S 盒是唯一非线性部件（混淆的核心，配合子密钥构成混淆），E 与 P 负责扩散。
  • S 盒查表：行 = 首尾两位，列 = 中间四位，都从 0 数；S1(011001)：行 1、列 12 → 9 = 1001。
  • 密钥编排：PC-1（64→56，去校验位）→ C0、D0 各 28 位 → 每轮循环左移 1 或 2 位（第 1、2、9、16 轮移 1，累计 28）→ PC-2（56→48）。
  • 雪崩效应：改明文 1 位或密钥 1 位（非校验位），密文约一半（≈32/64）的位改变；DES 约 5 轮后稳定在 32。无关随机串差异均值 32、标准差 4。无雪崩 → 穷举变成有方向的搜索。
  • DES 败于 56 位密钥：256 ≈ 7.21 × 1016；1998 Deep Crack 56 小时，1999 年 22 小时 15 分。算法本身 25 年无实用破解；差分分析 IBM 早已知晓、S 盒据此设计。DES 对线性分析（约 243 已知明文）并无专门抵抗，只是不实用。计时攻击是实现缺陷。密钥长度是保质期。
  • 三个杠杆：轮数（使已知攻击不优于穷举；DES 16 轮按教材口径差分 255.1 不比穷举省力，但 1992 年差分 247 选择明文、1994 年线性 243 已知明文都低于穷举，只是不实用）；F（非线性、SAC：单输入位变 → 每个输出位以 1/2 概率变；BIC：任意两输出位的变化相互独立；抗差分与线性）；密钥编排（知道部分密钥或子密钥位推不出很多其他子密钥位、无弱密钥）。找到起决定作用的约束。
  • 弱密钥 4 个：16 个子密钥相同，E(K, E(K, P)) = P；半弱密钥 6 对：E(K′, E(K, P)) = P。
  • 2DES 不是 112 位：中间相遇 E(K1, P) = D(K2, C)，运算约 257、存储 256 行；一对明密文留下约 248 个误报，第二对筛掉。
  • 3DES = E(K3, D(K2, E(K1, P)))；E–D–E 为了兼容单 DES；三密钥有效安全约 112 位（中间相遇只能劈成 1 层对 2 层），NIST 已禁止用于新的加密。AES：非 Feistel（SPN），解密须逐步求逆。
