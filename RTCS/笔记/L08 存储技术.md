# L08 存储技术

> [!info] 这一讲的骨架
> 主线一句话：**存储器没有万能解——又快、又大、又便宜，这三样只能同时要到两样。** 既然单一器件办不到，就把处在不同折中点上的器件**摞成一个层次**，让快的那层承担绝大多数访问，让慢的那层承担绝大多数容量。
> 这一讲的结构就是这条主线的展开：先给描述一块存储器的**八个维度**（其中"访问方式"和"性能"是后面全部讨论的词汇表），再把三组折中摆出来，然后用层次化解它，最后逐层看每一级具体是什么器件做的——DRAM、SRAM，以及 ROM 家族。
> **考情**：和 [[L07 通信与互连|L07]] 一样，2022、2023 两份真题里没有直接考 L08 的小问（我检索过 memory hierarchy、DRAM、SRAM、ROM、flash、volatile、access time、cycle time 这些词，只有 2023 卷 Q2(c) 的"**64 MB 主存、按字节编址**"沾边）。但这一讲有两个东西非学不可：一是关系式 $2^{A} = N$，2023 卷 Q2(c) 就是从它起步的；二是**整个 [[L09 高速缓存|L09]] 都建立在这一讲的层次与 Cache/主存结构上**，而 L09 是 Q2 区分值最重的一讲。
> 课程总览见 [[00 课程信息与考情]]。对应课件 `L08_Memory-Technologies_2024-2025`，33 页。

## 1 描述一块存储器：八个维度

![[L08 存储器的关键特性.png]]

课件开头两页把存储器的关键特性列成八类。这张清单本身就是"列举并简述"型小问的现成答案，但真正要动脑、后面反复用到的只有三条：**传输单位、访问方式、性能**。下面逐条过。

### 1.1 位置（location）

指存储器**在计算机内部还是外部**。

- **内部存储**常常就等同于**主存**；但处理器还需要自己的本地存储，形式是**寄存器**；**Cache 是内部存储的另一种形式**。
- **外部存储**由各种**外围存储设备**构成（SSD、光盘、磁盘、磁带），处理器**要经 I/O 控制器才够得着它们**。

"要经 I/O 控制器"这半句是有分量的：它意味着外部存储的访问必然要走 [[L06 计算机互连#1.2 互连结构必须支持的五种传送|L06 那五种传送]]里的 I/O 那几条，而不是像主存一样直接挂在地址线上。外部存储用的接口——SATA、SCSI、USB、FireWire——就是 [[L07 通信与互连#6 其余外设接口：一张清单|L07 清单里的那些]]。

### 1.2 容量（capacity）

按**字数**或**字节数**计（1 字节 = 8 位）。常见字长是 **8、16、32 位**。外部存储的容量一般按**字节**算。

### 1.3 传输单位，以及与它纠缠的两个概念

对**内部存储**，传输单位**等于进出存储模块的电气线数**。它**可能**等于字长，但**往往更大**——比如 64、128 或 256 位。

为了把这件事讲清楚，课件把三个相关概念并排摆出来：

| 概念 | 课件的定义 | 要注意的 |
| --- | --- | --- |
| **字**（word） | 存储器组织的"**自然**"单位。字长通常**等于表示一个整数所用的位数**，也**等于指令长度** | **例外很多**：CRAY C90 字长 64 位，却用 46 位表示整数；Intel x86 的指令长度是字节的各种倍数，而字长是 32 位 |
| **可寻址单位**（addressable unit） | 有些系统的可寻址单位就是字；但**很多系统允许按字节寻址** | 不管哪种，地址的位数 $A$ 与可寻址单位的个数 $N$ 之间**永远**满足下面那个关系式 |
| **传输单位**（unit of transfer） | 对主存，是**一次读出或写入的位数** | **不必等于一个字，也不必等于一个可寻址单位**。对外部存储，一次搬的往往比一个字大得多，这种大单位叫**块**（block） |

$$
2^{A} = N
$$

其中 $A$ 是地址的位数，$N$ 是可寻址单位的个数。

> [!warning] 这个式子是 Q2 区的地基，而且最容易在"单位"上翻车
> 它本身只是 [[L06 计算机互连#2.3 三组线各自决定什么|L06 "地址线宽度决定最大内存容量"]]的另一种写法。坑在于 **$N$ 数的是"可寻址单位"，不是字节也不是字**——到底是哪一个，由系统是按字节寻址还是按字寻址决定。
> 2023 卷 Q2(c) 给的是"**64 MB 主存，按字节编址**"：说了按字节编址，$N$ 才是字节数，于是 $N = 64\ \mathrm{MiB} = 2^{26}$，$A = 26$ 位。
> 如果题目改成"按 32 位字寻址"，同样 64 MB 就只有 $2^{24}$ 个字，地址只要 24 位。**先看清按什么编址，再取对数。**

### 1.4 四种访问方式

这四种是后面讨论 Cache 的词汇表，课件给的区分维度有两个：**访问时间恒不恒定**，以及**按地址找还是按内容找**。

| 方式 | 课件的说法 | 时间 |
| --- | --- | --- |
| **顺序访问**（sequential） | 存储器组织成一个个叫**记录**（record）的数据单位；访问**必须按特定的线性顺序**进行 | **可变** |
| **直接访问**（direct） | 涉及一个**共享的读写机构**；各个块或记录**基于物理位置**有唯一地址 | **可变** |
| **随机访问**（random） | **每个可寻址位置都有自己唯一的、物理上接好线的寻址机构**；访问某个位置所需的时间**与之前访问过什么无关，而且是常数**；任何位置都可以随机选中、直接寻址、直接访问 | **恒定** |
| **相联访问**（associative） | **按内容的一部分来取一个字，而不是按它的地址取**；每个位置有自己的寻址机构，取回时间**与位置和此前的访问模式都无关，是常数** | **恒定** |

课件还点了名：**主存和某些 Cache 系统是随机访问的**；**Cache 可能采用相联访问**。

> [!note] "相联"这个词现在不必深究，但要记住它解决的是什么问题
> **以下是我补的**：课件在 L08 关于相联只说了三句（按内容的一部分取、时间恒定、"Cache 可能采用相联访问"），为什么 Cache 需要它、要到 [[L09 高速缓存|L09]] 才讲。
> 一句话抓住它：**它不问"第几号位置"，而问"谁的内容里带着这个标记"**——所有位置同时自己比对，谁对上谁应答。
> 为什么 Cache 需要这种方式：Cache 里装的是主存某些块的副本，处理器手上拿着的是**主存地址**，而不是"这块在 Cache 的第几个格子"。要判断想要的块在不在，只能拿地址的一部分去和各个格子里记的那个标签比对——按地址直接问不出答案，必须按内容找。
> 那个"格子"叫**行**（line）、那个标签叫**标记**（tag），[[#3.2 Cache/主存结构|§3.2]] 会正式给出它们的定义。

### 1.5 三个性能参数

课件先说一句定位：**容量和性能是存储器最重要的两个特性**，性能用三个参数来刻画。

| 参数 | 定义 |
| --- | --- |
| **访问时间**（access time，又称**时延** latency） | 对**随机存取**存储器，是**完成一次读或写操作所需的时间**；对**非随机存取**存储器，是**把读写机构移动到目标位置所需的时间** |
| **存储周期时间**（memory cycle time） | **访问时间，加上第二次访问开始之前还需要的任何额外时间**。这段额外时间可能用来**等信号线上的瞬态消失**，或者**在破坏性读出之后把数据再生回去**。课件特别注明：这个参数**关心的是系统总线，而不是处理器** |
| **传输率**（transfer rate） | 数据进出存储单元的速率。对**随机存取**存储器，等于 $1/(\text{周期时间})$ |

> [!warning] 访问时间 ≠ 周期时间，这是最容易混的一对
> 访问时间问的是"**一次操作要多久**"；周期时间问的是"**隔多久才能开始下一次**"。周期时间 ≥ 访问时间，两者之差就是那段恢复时间。
> 课件给的两条恢复理由：**瞬态消失**是信号线上的电气现象；**破坏性读出后要再生**指的是读一次就会把存的东西破坏掉，所以读完必须写回去——哪种器件是这样，[[#4.2 DRAM 与 SRAM|§4.2]] 会讲。
> **以下是我补的**（课件在这里只有"关心的是系统总线而不是处理器"这一句话）：它的意思是，决定"隔多久能再来一次"的是**存储器这一侧连到总线上的时序**，不是处理器内部跑多快。这和 [[L06 计算机互连#3 总线设计的五个维度|L06 的总线时序]]是同一件事的两头，但要分清两者各管什么：**等待态要插几拍，看的是访问时间够不够一个总线周期**；而周期时间管的是**连续两次访问之间还要再等多久**。

### 1.6 物理类型与物理特性

**物理类型**，课件列了四种最常见的形式：**半导体、磁表面、光、磁光**。

**物理特性**，两组对立：

- **易失**（volatile）：**信息会自然衰减，或者在断电时丢失**。
- **非易失**（nonvolatile）：**一旦记录下来，信息就保持不变，直到被有意改写**；**不需要电力来保持信息**。
- **不可擦**（nonerasable）：**除非把存储单元毁掉，否则无法更改**。**半导体存储器里属于这一类的，叫只读存储器（ROM）**。

课件给的三条归属：

- **磁表面存储器是非易失的**；
- **半导体存储器可能易失，也可能非易失**；
- 不可擦的半导体存储器就是 ROM。

### 1.7 组织（organization）

指**存储模块在物理上怎么拼起来**。课件只列了这个名字，没有展开；真正把它讲开要等到 [[#4.3 一块 16 Mbit DRAM 长什么样|§4.3]] 看一块芯片内部的行列阵列。

## 2 三组折中，以及层次这个解法

### 2.1 三个问题

课件把存储器的设计约束归成三个问题：**要多大、要多快、能花多少钱**（how much, how fast, how expensive）。

这三个问题之间是**此消彼长**的，课件给了三条：

| 折中 | 方向 |
| --- | --- |
| 访问时间越短 | **每位成本越高** |
| 容量越大 | **每位成本越低** |
| 容量越大 | **访问时间越长** |

把三条连起来就是那个困境：**想要快，就贵，于是买不起大的；想要大，就只能选便宜的，而便宜的慢。**

### 2.2 解法不是选一种器件，而是用一个层次

课件的原话是：**走出这个困境的办法，不是依赖单一的存储部件或技术，而是采用存储层次**（memory hierarchy）。

![[L08 存储层次.png]]

顺着层次往下走，**同时**发生四件事：

1. **每位成本下降**；
2. **容量增大**；
3. **访问时间变长**；
4. **处理器访问这一层的频率下降**。

> [!warning] 这四条里第 4 条和前三条性质不同
> **以下是我补的**：课件只把四条平列，没有说哪条更关键，全篇也没有出现"局部性"这个词。
> 前三条说的是"**器件本身就是这样**"，第 4 条说的是"**我们把访问安排成这样**"。
> 如果处理器对各层的访问次数差不多，层次结构只会让平均访问时间变成各层的加权平均——比单用快存储器还慢。层次之所以有用，是因为**绝大多数访问都落在最上面那一两层**，慢的层很少被碰到，于是平均下来接近顶层的速度，而总容量接近底层。
> 这条"绝大多数访问集中在少数地方"的性质叫**局部性**（locality），[[L09 高速缓存|L09]] 会讲。

课件**最后一页**（Memory Summary）还给了各层的典型访问代价，这组数量级值得单独记住：

| 层 | 典型访问代价 | 归属 |
| --- | --- | --- |
| 寄存器 | **1 个周期** | 片上 · 主存储 |
| Cache | **约 10 个周期** | 片上 · 主存储 |
| 主存 | **约 100 个周期** | 主存储 |
| 闪存盘 | **约 100 万个周期** | 辅助存储 |
| 传统磁盘 | **约 1000 万个周期** | 辅助存储 |
| 远程辅助存储（如网络） | 课件未给 | 辅助存储 |

相邻两层之间大多差一个数量级，而**主存到闪存盘之间差了四个数量级**——这道缝就是 [[#4.5 非易失 RAM 在层次里的位置|§4.5]] 那些新器件想填的地方。

课件还补了三点：

- **用三级（寄存器、Cache、主存）这样的安排，利用的是"半导体存储器本身就有速度与成本各不相同的多个品种"这一事实**；
- **数据更持久地存放在外部大容量存储设备上**；
- **外部的非易失存储也叫辅助存储（secondary memory）或附属存储（auxiliary memory）**。

### 2.3 同一个思路再用一次：磁盘缓存

**磁盘缓存**（disk cache）是把层次思想往下再套一层：

- **拿主存的一部分当缓冲区**，暂存那些将要写出到磁盘的数据；
- 于是可以**用少数几次大传输，代替很多次小传输**；
- 需要时**从这块软件缓存里快速取回**，而不必慢慢从磁盘读。

注意它和 Cache 的区别：Cache 是**硬件**在主存与处理器之间加的一层，磁盘缓存是**软件**在磁盘与主存之间加的一层；但两者的逻辑完全一样——**在慢的东西前面放一块快的，让大部分访问停在快的那一侧**。

## 3 Cache 与主存：L09 的入口

### 3.1 为什么要有 Cache

课件给的定位很直接：**Cache 的设计目的，是把"昂贵的高速存储器的访问时间"和"便宜的低速存储器的大容量"结合起来。**

结构上就是：一块**相对大而慢**的主存，配一块**更小、更快**的 Cache。数据在两者之间的搬运有两种粒度——

- **CPU ↔ Cache：按字传输**（word transfer）；
- **Cache ↔ 主存：按块传输**（block transfer）。

这正是 [[#1.3 传输单位，以及与它纠缠的两个概念|§1.3]] 说的"传输单位不必等于一个字"：越往下，一次搬的越大。

**多级 Cache** 则是把同一招再用几次：**L2 比 L1 慢、而且通常更大；L3 比 L2 慢、而且通常更大。** 顺序是 CPU → L1 → L2 → L3 → 主存，越往外越慢越大。

### 3.2 Cache/主存结构

课件的 Figure 4.4 把两边的组织画在一起，这是 [[L09 高速缓存|L09]] 全部计算的出发点：

| | 主存 | Cache |
| --- | --- | --- |
| 基本单位 | $2^{n}$ 个可寻址的**字**，地址 $0 \dots 2^{n}-1$ | $C$ 个**行**（line），编号 $0 \dots C-1$ |
| 分组 | 分成 $M$ 个**块**（block），每块 $K$ 个字 | 每行装**一个块**，也是 $K$ 个字 |
| 额外的东西 | 无 | 每行还带一个**标记**（tag），用来记"我现在装的是主存的哪一块" |

注意这里的"**块**"和 [[#1.3 传输单位，以及与它纠缠的两个概念|§1.3]] 说的"外部存储一次搬的大单位"是同一个词的两种用法；这里特指**主存按 $K$ 个字切出来的分组**。

从上表能直接算出第一个关系式：

$$
M = \frac{2^{n}}{K}
$$

主存一共 $2^{n}$ 个字，每块 $K$ 个字，所以有 $M$ 块。

**第二个关系式课件没有给**（第 20 页只有图、没有文字），它出自 Stallings 正文，但不写出来后面就讲不下去：

$$
C \ll M
$$

**Cache 的行数远少于主存的块数。** 这是整件事的要害：既然行远少于块，一行就必然要在不同时刻装不同的块，于是才需要 tag 来说明"此刻装的是哪一块"，才需要讨论"新块该放进哪一行"——那就是 L09 的映射方式。

## 4 每一层具体是什么器件

### 4.1 半导体存储器类型

课件给的表就是 Stallings 的那张分类表。**表里列出的所有存储器类型都是随机访问的**——也就是说，每个字都通过接好线的寻址逻辑被直接访问。其中最常见的那种就叫**随机存取存储器（RAM）**。

> [!warning] 课件那张表里有一半的格子是空的，别照抄
> 课件这张表是从 Stallings 的 Table 5.1 重排来的，**重排时把原表纵向合并格里的内容漏掉了**——网格线是完整的，格子是真空着的，不是"合并后只印在中间行"。
> 从剩下内容的落位还看得出原表的合并范围："Read-mostly memory"落在 EEPROM 那一行（原表里它纵跨 EPROM–EEPROM–Flash 三行）、"Nonvolatile"落在 EPROM 那一行（原表里它纵跨 ROM 到 Flash 五行）。
> 按 Stallings 原表补全之后是这样：

| 存储器类型 | 类别 | 擦除方式 | 写入机制 | 易失性 |
| --- | --- | --- | --- | --- |
| **随机存取存储器 RAM** | 读—写存储器 | 电擦除，**按字节** | 电写入 | **易失** |
| **只读存储器 ROM** | 只读存储器 | **不可能** | **掩模**（masks） | 非易失 |
| **可编程 ROM（PROM）** | 只读存储器 | **不可能** | 电写入 | 非易失 |
| **可擦可编程 ROM（EPROM）** | 读—多存储器 | **紫外光，按整片** | 电写入 | 非易失 |
| **电可擦可编程 ROM（EEPROM）** | 读—多存储器 | 电擦除，**按字节** | 电写入 | 非易失 |
| **闪存（Flash）** | 读—多存储器 | 电擦除，**按块** | 电写入 | 非易失 |

> [!note] 这张表只要抓两条线就背下来了
> **第一条线是擦除的粒度，从粗到细**：ROM/PROM **不能擦** → EPROM **按整片擦**（还得拿紫外光照）→ Flash **按块擦** → EEPROM/RAM **按字节擦**。
> **第二条线是写入机制**：**只有 ROM 用掩模**（也就是在芯片制造时就把内容做死了），**其余全是电写入**。
> 剩下的一列最省事：**只有 RAM 是易失的，其余全部非易失。**
> "读—多存储器"（read-mostly memory）这个类别名也在提示用途：**读得多、写得少**——所以 EPROM、EEPROM、Flash 用来装固件和配置，不用来当工作内存。

### 4.2 DRAM 与 SRAM

![[L08 DRAM 与 SRAM 的单元.png]]

RAM 技术分成两支：**动态 RAM**（DRAM）与**静态 RAM**（SRAM）。

**DRAM**：

- 单元**把数据存成电容上的电荷**；
- **电容里有没有电荷**，就被解释成二进制的 1 或 0；
- **需要周期性地重新充电（刷新，refresh）才能维持数据**；
- "**动态**"这个词指的就是**电荷会自己漏掉的倾向——哪怕电源一直加着也会漏**。

**SRAM**：

- 是一种**用和处理器里相同的逻辑元件**做成的数字器件；
- 二进制值用**传统的触发器（flip-flop）逻辑门结构**存住；
- **只要一直供电，数据就一直在**。

两者的对比，课件对 **DRAM 列了六条、对 SRAM 只列了两条**（更快、用于 Cache）；下表 SRAM 一侧**加了括号的几格是我按对仗补的**，内容无误但不是课件写的：

| | DRAM（动态） | SRAM（静态） |
| --- | --- | --- |
| 易失性 | **都易失**——必须持续供电才能保住位值 | **都易失** |
| 造起来 | **更简单、单元更小** | （更复杂） |
| 密度 | **更高**（单元小 ⇒ 单位面积能放更多单元） | （更低） |
| 成本 | **更便宜** | （更贵） |
| 额外代价 | **需要配套的刷新电路** | （不需要刷新） |
| 速度 | 较慢 | **更快** |
| 用在哪 | **容量需求大的地方 ⇒ 主存** | **Cache，片上片外都用** |

一句话串起来：**DRAM 小而廉所以做得大，SRAM 快所以做得近。** 这正是 [[#2.2 解法不是选一种器件，而是用一个层次|§2.2]] 那个层次在半导体这一段的实现方式。

> [!note] 刷新这件事，对实时系统有额外的含义
> 刷新要占用存储器的时间，而且**什么时候刷新由刷新电路自己定**。这意味着一次访存偶尔会撞上刷新周期而变慢。
> 对[[L01 实时系统#7.3 设计嵌入式系统要考虑什么|L01 说的"提升平均性能的机制会以牺牲可预测性为代价"]]来说，这是同一类问题的又一个例子：DRAM 的平均性能很好，但**最坏情况访问时间**比平均值差。要求严格确定性的系统因此更偏好 SRAM 或片上存储。
> （这段是我补的，课件没有讨论刷新与实时性的关系。）

### 4.3 一块 16 Mbit DRAM 长什么样

课件拿一块 **16 Mbit、组织成 4M × 4 的 DRAM** 举例——意思是**一次读或写 4 位**。

- 逻辑上，存储阵列组织成**四个 2048 × 2048 的方阵**；
- 阵列元件由**水平（行）线与垂直（列）线**连接起来；
- **每条水平线接到它那一行里每个单元的"选择"端**；
- **每条垂直线接到它那一列里每个单元的"数据输入/读出"端**。

算一下账就知道这些数是自洽的：$2048 \times 2048 \times 4 = 4\mathrm{M} \times 4 = 16\ \mathrm{Mbit}$。

框图上还能读到几件事：地址线只画到 $A_{0} \dots A_{10}$，也就是 **11 根**，而且这 11 根**同时接进行地址缓冲器和列地址缓冲器**；芯片有 **RAS、CAS、WE、OE** 四个控制信号；还有**刷新计数器**与**刷新电路**，对应 [[#4.2 DRAM 与 SRAM|§4.2]] 说的那件事。

> [!note] 这 11 根地址线是怎么够用的：复用
> **以下整段是我补的——课件只画了引脚，没有解释这几个信号，全篇也没有出现 multiplex 这个词。**
> $2^{11} = 2048$ 只够选一行，而 4M 个位置本来需要 22 根地址线。做法是**把同一组线分两拍用**：**RAS**（row address strobe，行地址选通）先把行地址锁进行地址缓冲器，**CAS**（column address strobe，列地址选通）再把列地址锁进列地址缓冲器。
> 这样引脚数直接减半——**引脚是芯片上最贵的资源之一**；代价是一次访问要分两拍送地址。
> 这正是 [[L06 计算机互连#3 总线设计的五个维度|L06 五个维度里"专用 / 复用"]]那一条在存储芯片上的实例：**省线，但一次传输多花一个节拍。**

### 4.4 ROM 家族

**PROM（可编程 ROM）**：

- 是一种**更便宜的替代**；
- **非易失，而且只能写入一次**；
- **写入过程是电学方式进行的**，可以由**供应商或客户**在**芯片制造之后的某个时间**来做；
- **写入需要专门的设备**；
- 提供了灵活性与便利；
- 课件还把"**适合大批量生产**"列在 PROM 名下。

> [!warning] "适合大批量生产"这一条要留神
> Stallings 原文这句的主语是 **ROM**，不是 PROM——掩模的一次性成本高，所以**只有大批量才摊得平**。课件压缩要点时把主语丢了。
> PROM 的长处恰恰相反：**不必开掩模、可以在芯片出厂后再写**，所以它赢在小批量和后期编程。
> **答题按课件写，理解按这里。**（这个判断是我对照 Stallings 原文做的，课程材料里没有更正说明。）

**EPROM（可擦可编程 ROM）**：**擦除过程可以反复进行**；比 PROM 贵，但好处是**可以多次更新**。

**EEPROM（电可擦可编程 ROM）**：**可以在任何时候写入，而且不必先擦掉原有内容**；**把非易失性的好处与"可就地更新"的灵活性结合起来**；比 EPROM 贵。

**闪存（Flash memory）**，课件给了两页，要点合起来是：

- **在成本和功能上都介于 EPROM 和 EEPROM 之间**；
- **1980 年代中期**首次问世；
- **用和 EEPROM 一样的电擦除技术**；
- **不提供按字节擦除**——芯片被组织成"**一段存储单元在一次动作里被整体擦掉**"，这一下就叫一次 "flash"，名字由此而来；
- 因此**可以只擦某些块，而不必擦整片**；
- **每位只用一个晶体管**，所以达到了**和 EPROM 一样高的密度**；
- **内部存储和外部存储两种用途都在用**。

> [!warning] 闪存"介于两者之间"具体介于在哪，别记混
> 和 **EPROM** 比：闪存**不用紫外光、不用整片擦**，可以电擦除、按块擦——这是功能上的改进。
> 和 **EEPROM** 比：闪存**做不到按字节擦**，粒度粗——这是功能上的退让；换来的是**每位只用一个晶体管**，密度和 EPROM 一样高，因而便宜。
> 所以"介于中间"= **擦除粒度介于中间（整片 > 块 > 字节），成本也介于中间。**

闪存单元的结构：在普通晶体管的控制栅之下多了一个**浮栅**（floating gate）。浮栅被绝缘层包住，**往里注入或抽走电荷，就改变了这个晶体管的导通门限**——读的时候用这个差别区分 1 和 0。电荷被关在绝缘层里，所以**断电也不会跑掉**，这就是它非易失的原因。（课件只给了三张单元结构图，这段解释是我补的。）

### 4.5 非易失 RAM 在层次里的位置

课件第 32 页给了一张图，把几种**非易失 RAM** 新器件放进速度—成本的坐标里。图左侧是**两个方向相反的竖直箭头**：**往上**是性能与耐久性递增，**往下**是每位成本递减、容量或密度递增。

关键是这张图的结构——**它不是一串七级阶梯**：

- 金字塔里的**实体层只有四个**：**SRAM、DRAM、NAND 闪存、硬盘**；
- **STT-RAM、PCRAM、ReRAM 不是独立的层**，而是三个**虚线框**，**每个都横跨相邻的两层**：**STT-RAM 跨 SRAM–DRAM**，**PCRAM 跨 DRAM–NAND 闪存**，**ReRAM 跨 NAND 闪存–硬盘**。

这个画法本身就是结论：**这些非易失 RAM 各自去填常规层级之间的那道缝**——既想要上面那层的速度，又想要下面那层的容量与非易失。回头看 [[#2.2 解法不是选一种器件，而是用一个层次|§2.2]] 那张访问代价表，主存（约 100 个周期）到闪存盘（约 100 万个周期）之间差了四个数量级，这就是最值得填的一道缝。

课件没有展开这几种器件各是什么，只给了它们的相对位置。

## 本讲速记

- **八个维度**：位置、容量、传输单位、访问方式、性能、物理类型、物理特性、组织。
- **位置**：内部（寄存器、Cache、主存）/ 外部（SSD、光盘、磁盘、磁带，**要经 I/O 控制器**）。**容量**按字或字节；常见字长 **8/16/32 位**。
- **字 / 可寻址单位 / 传输单位**三者互不相等：**字**是"自然"单位，通常等于整数位数和指令长度（**例外很多**：CRAY C90 字长 64 位但整数 46 位；x86 字长 32 位而指令长度不定）；**传输单位**对内部 = 进出模块的电气线数，常大于字长（64/128/256 位），对外部叫**块**。
- $2^{A} = N$：$A$ 是地址位数，$N$ 是**可寻址单位**个数。**先看清按什么编址再取对数**——64 MB 按字节编址是 26 位，按 32 位字寻址只要 24 位。
- **四种访问方式**：**顺序**（记录，必须按线性顺序，时间可变）、**直接**（共享读写机构，按物理位置有唯一地址，时间可变）、**随机**（每个位置有接好线的寻址机构，时间与历史无关且恒定）、**相联**（**按内容的一部分取，而不是按地址取**，时间恒定）。主存与某些 Cache 是随机；**Cache 可能用相联**。
- **三个性能参数**：**访问时间**（随机存取 = 一次读写的时间；非随机 = 把读写机构移到位的时间）、**存储周期时间**（= 访问时间 + 第二次访问开始前的额外时间，用于**等瞬态消失**或**破坏性读出后再生**，**关心的是系统总线不是处理器**）、**传输率**（随机存取时 $= 1/\text{周期时间}$）。
- **物理类型**：半导体 / 磁表面 / 光 / 磁光。**磁表面非易失；半导体可易失可非易失；不可擦的半导体就是 ROM。**
- **三组折中**：访问时间越短→每位成本越高；容量越大→每位成本越低；容量越大→访问时间越长。**出路是层次，不是单一器件。**
- **往下走四件事**：每位成本下降、容量增大、访问时间变长、**处理器访问它的频率下降**。（课件只平列四条；"第 4 条才是前三条能换来好处的前提"是我补的。）
- **磁盘缓存**：拿主存的一部分当缓冲，**用少数几次大传输代替很多次小传输**，并能从软件缓存快速取回。
- **Cache/主存结构**：主存 $2^{n}$ 个字、分成 $M$ 个块、每块 $K$ 个字；Cache $C$ 行、每行一块加一个 **tag**；$M = 2^{n}/K$ 从图上直接算得，而 **$C \ll M$ 课件没写**（出自 Stallings），但正因为行远少于块，才需要 tag 和映射方式。**CPU↔Cache 按字传，Cache↔主存按块传。** 多级：L2 比 L1 慢且通常更大，L3 比 L2 慢且通常更大。
- **半导体存储器类型表**（课件里合并单元格看起来是空的，要补全）：**只有 ROM 用掩模写入，其余全是电写入；只有 RAM 易失，其余全非易失**；擦除粒度 **ROM/PROM 不可擦 → EPROM 整片（紫外光）→ Flash 按块 → EEPROM/RAM 按字节**。
- **DRAM**：电荷存在**电容**上，**必须周期性刷新**，"动态"指的就是漏电倾向；**简单、小、密度高、便宜，但要刷新电路 ⇒ 用作主存**。
- **SRAM**：用**触发器**存，**只要供电就不丢、不用刷新**；**更快 ⇒ 用作 Cache（片上片外都用）**。**两者都是易失的。**
- **16 Mbit DRAM（4M × 4）**：一次读写 **4 位**；逻辑上是**四个 2048 × 2048 的方阵**；行线接每个单元的**选择端**，列线接**数据输入/读出端**；地址线 $A_{0} \dots A_{10}$ 共 **11 根**，芯片有 RAS/CAS/WE/OE 与刷新计数器。（**"11 根靠 RAS/CAS 分两拍复用"是我补的解释**，课件只画了引脚没有说明。）
- **ROM 家族**：**PROM** 非易失、**只能写一次**、电写入、**需要专用设备**；课件把"适合大批量生产"也列在它名下，但 Stallings 原文那句的主语是 **ROM**；**EPROM** 可**反复擦除**（紫外、整片），比 PROM 贵；**EEPROM** **随时可写且不必先擦**，比 EPROM 贵；**闪存**成本与功能都**介于 EPROM 与 EEPROM 之间**，**电擦除但不支持按字节擦**（按块），**每位一个晶体管**所以密度和 EPROM 一样高，**1980 年代中期**问世。
- **非易失 RAM 层次图（第 32 页）**：实体层只有四个——**SRAM、DRAM、NAND 闪存、硬盘**；**STT-RAM、PCRAM、ReRAM 不是独立层**，而是三个各自**横跨相邻两层**的虚线框（STT-RAM 跨 SRAM–DRAM，PCRAM 跨 DRAM–NAND 闪存，ReRAM 跨 NAND 闪存–硬盘）。它们要填的就是层级之间的缝。
- **各层典型访问代价（课件最后一页）**：寄存器 **1 个周期**、Cache **约 10**、主存 **约 100**、闪存盘 **约 100 万**、传统磁盘 **约 1000 万**；前三层属**主存储**（寄存器与 Cache 在 CPU 片上），后三层属**辅助存储**。**主存到闪存盘之间差四个数量级。**
- **考情**：两份真题没有直接考 L08 的小问；但 $2^{A} = N$ 是 2023 卷 Q2(c) 的第一步，而整个 L09 都架在这一讲的层次与 Cache/主存结构上。
