# 大四上课程包 · RTCS / 控制 / 信息安全

实时计算系统（RTCS）、控制、信息安全（IS）三门课的课程笔记、实验交付物与往届真题。
作者 [@AlanCommitK](https://github.com/AlanCommitK)，随学期进度持续更新。

## 这个仓库该怎么用

**它是一个 Obsidian 笔记包，不是给 GitHub 网页看的。**

1. 下载整个仓库：右上角 `Code → Download ZIP`，或 `git clone https://github.com/AlanCommitK/Fourth-year1stSemester.git`
2. 把整个文件夹放进你自己的 Obsidian 仓库（vault）里
3. 在 Obsidian 里打开阅读

笔记大量使用 Obsidian 的 callout（`> [!note]`）、`[[双链]]`、LaTeX 公式与折叠块。
这些语法在 GitHub 网页上不渲染，会原样显示成代码，又乱又卡。
**在 GitHub 网页里逐个点开 `.md` 文件是错误的打开方式。**

没有 Obsidian 的话，[obsidian.md](https://obsidian.md) 是免费的。

## 目录结构

```
<课程>/
├── 笔记/
│   ├── *.md          按课件整理的知识点笔记（Obsidian 里读）
│   ├── HTML/         同一份内容的网页版，双击用浏览器打开
│   └── 附件/         笔记引用的图片
├── 实验/
│   ├── *.md          实验原理、操作步骤、踩坑记录
│   └── 交付物/       提交给课程的代码与报告
└── 资料/
    └── 真题/         往届期末真题
```

`HTML/` 里那份是同一批内容为「读」优化过的版本——有配图、有高亮、部分带交互演示，
比 Markdown 好读得多，但没有双链和全库搜索。两份配合着用：
在 Obsidian 里检索与串联，在浏览器里啃难懂的部分。

`.tools/` 是生成这个包的同步脚本，与阅读无关，可以忽略。

## 不包含什么

- **课件原件**：属于校方材料，体积也大，请从课程平台自取。
- **实验手册原件**：同上。

## 两点使用提醒

- 包内笔记的 `[[双链]]` 大多指向包内其它笔记。Obsidian 解析不带路径的双链时会优先匹配
  同文件夹下的同名文件，所以正常情况下不会串到你自己的笔记上；把整个包放进一个独立文件夹里最保险。
- 图片放在各自笔记文件夹下的 `附件/` 中，别单独挪动，否则图会断。
